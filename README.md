# Concomitant_LLT_AC_systematic_review_and_meta_analysis

This repository contains R code for conducting meta-analysis across different outcomes, with workflows for Bayesian analysis using brms package, visualization using forplo package, heterogeneity assessment, meta-regression, leave-one-out sensitivity analysis, and publication-bias diagnostics using ggplot.

## Required R packages

Install the following packages before running the analysis:

```r
install.packages(c(
  "meta",
  "metafor",
  "brms",
  "dplyr",
  "ggplot2",
  "readr",
  "tidyr",
  "purrr",
  "broom",
  "bayesplot"
))
```
